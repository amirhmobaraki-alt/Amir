# ساخت APK برنامه «ویزیت کارشناسان دوو»

این بسته شامل فایل HTML اصلی شما و تنظیمات ساخت اندروید با Capacitor است. فایل‌های کتابخانه‌ای XLSX، html2canvas و jsPDF هنگام اجرای GitHub Actions از بسته‌های نسخه‌بندی‌شده npm دریافت و در `www/lib` قرار می‌گیرند؛ بنابراین لازم نیست آن‌ها را جداگانه دانلود کنید.

## ساخت APK با گوشی

1. فایل ZIP را از حالت فشرده خارج کنید.
2. در مرورگر گوشی وارد https://github.com شوید و وارد حساب خود شوید.
3. از منوی `+` گزینه `New repository` را بزنید.
4. نامی مثل `daewoo-visit-android` انتخاب و Repository را بسازید.
5. داخل مخزن تازه، `Add file` سپس `Upload files` را انتخاب کنید.
6. همه فایل‌ها و پوشه‌های داخل این بسته را بارگذاری کنید؛ پوشه مخفی `.github` هم باید بارگذاری شود.
7. تغییرات را با `Commit changes` ثبت کنید.
8. از زبانه `Actions`، گردش‌کار `Build Android APK` را انتخاب کنید. اگر خودکار اجرا نشد، `Run workflow` را بزنید.
9. پس از سبز شدن اجرای Build، همان صفحه را پایین بروید و از بخش `Artifacts` فایل `daewoo-visit-debug-apk` را دانلود کنید.
10. ZIP دانلودشده را در گوشی باز کنید و `app-debug.apk` را نصب کنید. اگر اندروید اجازه خواست، مجوز نصب برنامه از همین منبع را فعال کنید.

## نکات مهم

- این خروجی، APK آزمایشی (debug) برای نصب مستقیم است؛ برای انتشار عمومی در Google Play باید نسخه release امضاشده ساخته شود.
- پروژه به فایل اکسل ورودی شما نیاز دارد تا داده‌های فروشگاه‌ها و عملکرد را بارگذاری کند. خود HTML فقط منطق برنامه و فهرست اولیه پیش‌فاکتور را دارد.
- GPS به مجوز موقعیت مکانی اندروید و اجازه دسترسی مرورگر داخلی نیاز دارد. رفتار نهایی GPS و انتخاب/بارگذاری فایل باید پس از نصب روی گوشی آزمایش شود.
- داده‌های ثبت‌شده در حافظه محلی برنامه نگهداری می‌شوند. پیش از حذف یا نصب مجدد برنامه، از اطلاعات مهم خروجی/پشتیبان بگیرید.
- برای ساخت، GitHub باید بتواند بسته‌های npm و ابزارهای اندروید را از اینترنت دریافت کند.
